# Beauty Boutique

## A preview of a home page for a quirky, colorful makeup line website!

- Using React/Vite for the meat of the project and Bulma/SCSS for the styling, you can see several sections while scrolling down the page, various images of makeup, other website "featured in" and the social media outreach down at the bottom.
- Routes for other pages were created as placeholders but mostly there for display.
